DeepPilot 0.10.0-alpha.2

## 中文

- **恢复 RC 兼容**。DSH `0.2.2` 的 RC 系列可以使用手机打开 DSH 网页并浏览项目文件，文件搜索从 `rc.2` 起可用。
- **兼容性**。本版也支持 DSH `0.2.3` 的 Alpha 系列，其中 `alpha.1` 的 npm 安装包需要上游依赖修正才能启动；同系列 RC 已纳入版本范围，待官方发布后验证。

## English

- **Restored RC compatibility.** The DSH `0.2.2` RC series can open DSH Web and browse project files from the phone, with file search available from `rc.2`.
- **Compatibility.** This release also supports the DSH `0.2.3` Alpha series. The `alpha.1` npm build needs an upstream dependency fix to start, and future RCs in this series are eligible for activation pending runtime verification.
