## 四、执行、权限与附件约定

1. 主机目录按会话查询。插件通过官方 `typertGateway.invoke` 传具名参数，让官方完成智能体查找、冷恢复和作用域覆盖。新版创建独立 owner 身份且 `interactions:none`，不接管审批瀑布；旧版复用 `connection.operator`。手机权限门继续由已认证设备的范围控制，禁止小组件调用。
2. 起始斜杠命令与普通消息分通道，执行不创建普通用户消息。主机命令点选只补全，发送才执行；原生入口点选后开选择器，用户确认具体操作后生效。未知名称只在确认为当前技能时按技能发送；未知指令不发给模型。显式点选同名技能时保留技能含义，手输同名词优先命令。
3. `/model`、`/file` 是客户端保留入口；若主机贡献同名命令，拒绝混合目录，防止误执行。内置界面装饰按精确来源识别，扩展插件的同名命令仍走主机执行。
4. 权限目录来自真实主机，显示当前选择；自动审查或实际沙盒为完全访问的选项需二次确认。目录变化、重连、切换会话会关闭旧权限与反馈界面。直接手输完整 `/permission <value>` 沿用网页带参数命令语义。
5. 命令附件最多四个，发送前先校验目录是否声明支持。图片直接提交；文档沿用手机现有提取结果，编码为 UTF-8 文本文件并经官方上传取得收据，不冒充原始 PDF/二进制。主机继续检查具体参数及附件组合。
6. 常见压缩结果与状态用中文；扩展命令的成功正文由主机提供。失败保留命令草稿和附件，不自动重试，网络中断时主机可能已经执行，重试前应检查会话。普通技能继续沿用原有投递不确定标记，避免重复消息。
7. 技能和命令由内存与磁盘目录缓存提供，详见[目录缓存](移动端目录缓存.md)。两者并行读取，单个目录失败仍显示另一目录，并允许重试；继续输入仅本地筛选。名称、说明各一行，普通字号最多三条，其余内部滚动。

## 五、日志与反馈边界

1. 归档在主机进程内复用官方共享 Fetch 路由，包含子会话和附件；不自制聊天摘要 ZIP。每块最多 48 KiB，具有连续序号；连接输出缓冲超过 256 KiB 时等待。断线或十分钟超时中止归档读取，无最终成功确认时客户端删除临时文件。
2. 客户端核对序号、块长度、最终会话、块数和总字节后才打开系统分享。归档分块不进入重放缓存；断线需用户重新发起。没有单独取消正在执行的主机命令的协议，也不声称主机命令回滚。
3. 成功导出的文件留在独立临时/缓存区域，防止分享目标尚未读取就被删除；下一次导出清理超过一天的历史文件。Android 文件提供器仅开放指定缓存目录。
4. 反馈保存到当前主机的会话日志，不自动发送给模型或外部服务。保持七种上游分类；空文本可记录查看会话的请求。
