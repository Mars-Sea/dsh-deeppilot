# 设置页布局与验收

## 展示与行为

- 页头显示用途与刷新；连接卡片合并服务状态、当前连接数和总开关，下面是局域网与远程连接行。
- 已配对设备列表显示名称、App 版本和最近在线。指纹、自定义名称标记、重命名和删除在各行的“更多操作”中；删除继续采用行内二次确认。
- “添加手机”按需生成一次性配对信息；切换地址保持面板展开并重新生成，凭据过期后移除二维码。端口默认 3098，公网来源上限默认 8，配置、鉴权和协议不随布局改变。
- 连接参数、远程帮助、诊断工具、系统信息默认收起。收起区域使用原生 `hidden`，退出键盘焦点顺序和无障碍读取顺序；参数草稿仍保留。
- 桌面次要按钮高 28px，添加按钮为 30px 的轻描边样式，自有操作的触屏点击区域至少 44px。总开关、局域网、远程连接和调试日志直接使用 DSH 内置 `Switch`，尺寸、配色、滑块、焦点及动效均由宿主管理，不覆盖开关样式。正文 14px，辅助文字至少 12px。颜色使用 DSH 主题变量，图标统一为线性单色 SVG。
- 历史失败条数是记录摘要，不表示服务当前不可用；当前连接相位由连接行展示。错误先给中文结论，原始诊断码放在括号内。

## 宿主开关接入

| 实际接口与来源 | 已读范围及用法 |
| --- | --- |
| `@deepseek-ai/dsh-client-ui-primitives` → `Switch` | 已读 `lib/types/Switch.d.ts`、`lib/index.js` 的开关实现及 `lib/Switch.module.css`；使用 `checked`（状态）、`disabled`（禁用）、`label`（无障碍名称）、`onChange(next)`（新状态回调）。可选 `title`、`className` 不传。 |
| DSH 通用设置 `dsh-client-ui-settings-general/lib/client.js` | 已读内置开关调用，按相同方式接入。 |
| `dsh-web-frontend/dist/assets/index-*.js` 平台模块表 | 已确认兼容下界 `0.2.1-rc.5` 和当前本机 `0.2.2-rc.1` 都提供该模块与 `Switch` 导出。其他原语控件与本次改动无关，未展开审计。 |

| 差异分类 | 当前结果 |
| --- | --- |
| 双方都有 | 布尔状态、禁用、名称与状态回调均直接对接。 |
| 上游有我方未用 | `title`、`className`，本页不需要额外提示或开关样式。 |
| 我方有上游没有 | 四项配置的能力检查与保存回调，保留在页面业务层。 |
| 都没有 | 无待补开关接口；不维护自绘开关。 |

此包是 DSH 隐式提供的浏览器基础模块，正式客户端保留宿主模块引用，不加入运行依赖或 `dsh.client.inject` / `external`。精确版本的开发依赖仅供类型检查及独立浏览器夹具使用。夹具加载官方包内原样的开关代码与 CSS，不把测试适配器带入正式产物。

## 验收

```sh
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
```

已安装 Chrome 时可用 `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`。
`npm run preview:settings` 启动仅监听 `127.0.0.1:4781` 的浏览器夹具，使用正式组件与样式、模拟报告和操作边界；不读取个人 DSH 数据，不启动 Funnel，也不发送真实通知。

端到端断言覆盖浅色/深色、桌面与 320/390px 视口、最小字号和图标、折叠焦点与草稿、设备详情/重命名/删除确认、配对切换/复制/失败/过期、中文错误、空/加载/长名称/待授权状态和自有操作触屏点击区域。四个开关分别验证鼠标/空格切换、禁用及配置回写；轨道、滑块和触屏尺寸与未嵌入插件的同一官方开关比较。夹具验证页面与回调接线，不代替真实主机及手机的协议集成验收。
