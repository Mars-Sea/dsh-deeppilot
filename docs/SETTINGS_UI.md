# 设置页布局与验收

## 展示与行为

- 页头显示用途与刷新；连接卡片合并服务状态、当前连接数和总开关，下面是局域网与远程连接行。
- 已配对设备列表显示名称、App 版本和最近在线。指纹、自定义名称标记、重命名和删除在各行的“更多操作”中；删除继续采用行内二次确认。
- “添加手机”按需生成一次性配对信息；切换地址保持面板展开并重新生成，凭据过期后移除二维码。端口默认 3098，公网来源上限默认 8，配置、鉴权和协议不随布局改变。
- 连接参数、远程帮助、诊断工具、系统信息默认收起。收起区域使用原生 `hidden`，退出键盘焦点顺序和无障碍读取顺序；参数草稿仍保留。
- 桌面次要按钮高 28px，添加按钮为 30px 的轻描边样式，开关轨道 34×20px；触屏点击区域至少 44px。正文 14px，辅助文字至少 12px。颜色使用 DSH 主题变量，图标统一为线性单色 SVG。
- 历史失败条数是记录摘要，不表示服务当前不可用；当前连接相位由连接行展示。错误先给中文结论，原始诊断码放在括号内。

## 验收

```sh
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
```

已安装 Chrome 时可用 `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`。
`npm run preview:settings` 启动仅监听 `127.0.0.1:4781` 的浏览器夹具，使用正式组件与样式、模拟报告和操作边界；不读取个人 DSH 数据，不启动 Funnel，也不发送真实通知。

端到端断言覆盖浅色/深色、桌面与 320/390px 视口、最小字号和图标、折叠焦点与草稿、设备详情/重命名/删除确认、配对切换/复制/失败/过期、中文错误、空/加载/长名称/待授权状态和触屏点击区域。夹具验证页面与回调接线，不代替真实主机及手机的协议集成验收。
