DeepPilot 0.10.0-alpha.1

## 中文

- **在手机上打开 DSH 网页**。开启电脑端网页功能后，可通过 DeepPilot 进入新版 DSH 的 Web 界面。
- **项目文件与附件候选**。切换 DSH 工作目录后，手机端项目文件列表和 `@` 附件候选会跟随当前工作目录。
- **兼容性**。本预发布版最低要求 DSH `0.2.3-alpha.2`，现有手机配对可以继续使用。

## English

- **Open DSH Web on your phone.** With the Host Web feature enabled, you can open the updated DSH Web interface from DeepPilot.
- **Project files and attachment suggestions.** When the DSH working directory changes, the project file list and `@` attachment suggestions on the phone follow it.
- **Compatibility.** This prerelease requires DSH `0.2.3-alpha.2` or later in the `0.2` series, and existing phone pairings continue to work.
