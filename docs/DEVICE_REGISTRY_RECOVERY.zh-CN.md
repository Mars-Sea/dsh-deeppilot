# 设备注册表丢失后的恢复

[English](./DEVICE_REGISTRY_RECOVERY.md)

电脑上用 `$DSH_HOME/deeppilot/devices-v2.json`（未设置 `DSH_HOME` 时为
`~/.dsh/deeppilot/devices-v2.json`）记录已配对的手机：每台手机的**公钥**、权限范围、
显示名称、通知偏好和推送注册。私钥永远不离开手机（真机在 Secure Enclave 中），
所以这个文件是电脑认出已配对手机的唯一依据。文件丢了，手机就无法证明自己的身份，
唯一的出路是重新配对。

## 你会看到什么

| 情形 | 电脑端 | 手机端 |
| --- | --- | --- |
| 文件被删，或数据目录是新的 | 以空设备列表启动，不报错：缺文件与首次运行无法区分。启动日志里的 `device registry loaded from ...: 0 device(s), 0 push registration(s)` 就是线索 | 所有手机被关闭码 `4401` 拒绝，提示"配对已失效" |
| 文件不可读（被截断、磁盘错误） | 启动时记一条 `[deeppilot] device registry unreadable, starting empty: ...`，随后报告 `0 device(s)`，之后同上 | 同上 |
| 在设置页只删除了一台设备 | 仅该设备被拒绝，其余不受影响 | 仅该手机出现同样提示 |

手机无法区分这几种情形：被吊销的设备拿到的同样是 `4401`。如果所有手机同时失败，先怀疑
注册表；只有一台失败，先怀疑它被删除。

## 动手之前

1. **先停止 DeepSeek Harness。**插件只在启动时读一次注册表，之后按内存内容重写文件，
   运行中手工修改会被覆盖。
2. **把损坏的文件另存一份**（`cp devices-v2.json devices-v2.json.bad`）。第一次成功配对
   会用新内容覆盖它，而被截断的文件里也许还有可挽回的条目。
3. **不要删除 `host-id`。**它是所有手机都保存着的 Host 身份（`audience`）；换了新的
   `host-id`，即便注册表恢复了，所有配对也都作废。如果 `host-id` 本身格式损坏，插件会
   拒绝启动，请从备份恢复，而不是删除。

## 恢复步骤

### A. 有 `devices-v2.json` 的备份

该文件是原子替换写入的（先写临时文件再改名），任何时刻拷贝出来的都是一致的快照。

1. 停止 DeepSeek Harness。
2. 把备份放回 `$DSH_HOME/deeppilot/devices-v2.json`，权限设为 `0600`。
3. 启动 DeepSeek Harness。启动日志会报告载入了多少台设备和多少条推送注册。
4. 在每台手机上把 App 切回前台（或使用重试操作）。被 `4401` 拒绝过的手机会停止自动重试，所以要等你重新打开 App 才会重连，而不是电脑恢复的那一刻。无需重新配对。

备份之后的变更（新配对、改名、删除的设备）会一并回退。备份之后被你删除的设备会重新
可用，请再删除一次。

### B. 没有可用备份

每台手机都需要重新配对。

1. 启动 DeepSeek Harness，打开 DeepPilot 插件设置页。
2. 显示配对二维码（或可复制的配对文本）。配对码 5 分钟有效，只能用一次。
3. 在每台手机的 App 设置里编辑该主机，扫描新二维码（或粘贴配对文本）。如果不生效，
   就在 App 里删除该主机后重新添加。
4. 如果旧注册表恢复了一部分，在设置页清理多余的条目。

会被重置的内容：自定义设备名称、每台设备的通知偏好和权限范围（回到默认值）。推送注册和
实时活动令牌会自动恢复，因为 App 每次连接都会重新注册。

会话、项目和模型不受影响，它们属于 DeepSeek Harness，不属于本插件。

## 同样会迫使重新配对的相关文件

| 文件或目录 | 丢失后果 |
| --- | --- |
| `host-id` | 新的 audience：所有手机都要重新配对 |
| `lan-tls/` | 新的证书密钥：经局域网配对的手机在重新配对前会拒绝该主机（Funnel 配对不受影响） |
| `tailscale/` | Funnel 的 Tailscale 节点状态。预期会出现新节点并需要重新授权 Funnel；局域网配对不受影响 |

## 保留备份

每次配对或删除设备后，把 `devices-v2.json` 和 `host-id` 一起拷贝到 `DSH_HOME` 之外。
这份拷贝要像对待任何能访问你会话的文件一样保管：它列出了允许连接的公钥，但无法用来
冒充手机。
